# Birthday Website

A small birthday website made with plain HTML, CSS, and JavaScript.

## What's inside

- Passcode lock screen
- Music player with playlist
- Chat-style birthday messages
- Falling snow, leaves, or petals in the background

## Files

```
index.html
css/style.css
js/script.js
images/
```

## How to use

Open `index.html` in your browser, then enter the passcode.

## Edit

- Passcode, songs, and messages: `js/script.js`
- Colors, fonts, and background photo: `css/style.css`
